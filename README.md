ابن سويد للسفريات والسياحة (Ibn Sowaid Travel & Tourism)
موقع إلكتروني تعريفي وتفاعلي لمكتب ابن سويد للسفريات والسياحة، يتميز بتصميم عصري وهوية بصرية متكاملة (الأزرق الداكن والذهبي)، ويهدف إلى تسهيل استعراض خدمات السفر والعمرة وخدمات الإرساليات وتقديم الطلبات والاستفسارات المباشرة عبر الواتساب.

🛠️ التقنيات المستخدمة (Tech Stack)
HTML5: بناء الهيكل الأساسي واستخدام عناصر دلالية متقدمة (Semantic Tags) لدعم محركات البحث والوصولية، مع دعم كامل لاتجاه اللغة العربية (RTL).

CSS3: تصميم واجهة المستخدم بتنسيقات عصرية، وألوان الهوية البصرية (الكحلي والذهبي)، وتجاوب تام (Responsive) مع كافة مقاسات الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).

JavaScript (Vanilla JS): التحكم الديناميكي بالقوائم، تفاعل نموذج الطلبات، إدارة الحقول الشرطية (مثل مسارات الإرساليات)، وتكامل فوري لفتح تطبيق الواتساب بالرسائل المجهزة.

Vercel & GitHub: استضافة ونشر مستمر وسريع للموقع.

📋 المميزات والخدمات
عرض شامل ومحدّث للخدمات:

خدمات العمرة المتكاملة والترتيبات المصاحبة.

الزيارة العائلية والتأشيرات والفيز.

حجوزات النقل والسفر (طيران، باصات، سيارات).

إجراءات الجوازات عن بُعد ومعاملات الفحوصات في عدن.

قسم خاص بخدمات الإرساليات: دعم مسارات الشحن المحددة (من اليمن إلى السعودية و من صنعاء إلى الحديدة) مع تفاصيل إضافية لوصف الشحنة.

تكامل ذكي ومباشر مع الواتساب: إرسال الطلب تلقائياً مع تفاصيل العميل والخدمة المختارة إلى أحد الرقمين المعتمدين للمكتب (774642465 أو 771402519) بعد مراجعتها من قِبل المستخدم.

أيقونة مخصصة (Favicon): تصميم أيقونة احترافية خاصة بشريط المتصفح متوافقة مع الهوية البصرية.

واجهة متجاوبة وسريعة: تجربة مستخدم عالية السلاسة بدون الحاجة لإنشاء حساب أو تعقيدات في تقديم الطلب.
